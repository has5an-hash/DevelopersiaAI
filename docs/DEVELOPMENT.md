# راهنمای توسعه Developersia AI

## پیش‌نیازها

- Node.js نسخه 22.12 یا جدیدتر
- npm نسخه 10 یا جدیدتر
- PostgreSQL نسخه 16
- PHP 8.1+ و WordPress 6.5+ برای تست افزونه
- دامنه و HTTPS برای محیط عمومی

## راه‌اندازی محلی

1. مخزن را clone کنید و وارد پوشه پروژه شوید.
2. فایل نمونه را کپی کنید:

   ```bash
   cp .env.example .env
   ```

3. مقادیر محرمانه را تولید و در فایل `.env` قرار دهید:

   ```bash
   openssl rand -hex 48
   openssl rand -hex 32
   ```

   خروجی اول برای `JWT_SECRET` و خروجی دوم برای `ENCRYPTION_KEY` است. کلید رمزنگاری باید دقیقاً ۶۴ نویسه هگزادسیمال باشد.

4. PostgreSQL را اجرا کنید و `DATABASE_URL` را تنظیم کنید.

   اگر برنامه پشت reverse proxy قرار دارد، مقدار `TRUST_PROXY_HOPS` را برابر تعداد پروکسی‌های مورداعتماد بین اینترنت و برنامه قرار دهید (مثلاً `1` برای یک reverse proxy). مقدار پیش‌فرض `0` است؛ فقط وقتی آن را تغییر دهید که تمام پروکسی‌های ورودی تحت کنترل شما باشند.

5. وابستگی‌ها و دیتابیس را آماده کنید:

   ```bash
   npm install
   npx prisma generate
   npm run db:migrate
   npm run db:seed
   ```

6. سرور را اجرا کنید:

   ```bash
   npm run dev
   ```

سلامت سرویس از مسیر `/health` قابل بررسی است. صفحه ورود پنل در `/login` و پنل مدیریت سایت‌های متصل در `/dashboard` قرار دارد. پنل از حساب‌های موجود در دیتابیس استفاده می‌کند و ثبت‌نام عمومی در این نسخه فعال نیست.

## ساخت حساب مدیر اولیه

در `.env` مقدارهای `ADMIN_EMAIL` و `ADMIN_PASSWORD` را تعیین کنید. رمز عبور باید حداقل ۱۴ کاراکتر باشد. سپس `npm run db:seed` را اجرا کنید. اگر ایمیل از قبل وجود داشته باشد، Seed فقط نقش حساب را مدیر می‌کند و رمز فعلی را تغییر نمی‌دهد. برای تغییر رمز، از فرایند مدیریت امن حساب استفاده کنید.

## ساخت کد اتصال وردپرس

پس از ساخت حساب مدیر:

```bash
npm run pair:code -- --email admin@example.com --ttl-minutes 15
```

کد فقط یک بار نمایش داده می‌شود و حداکثر ۶۰ دقیقه اعتبار دارد. آن را در تنظیمات افزونه WordPress وارد کنید. همچنین پس از اتصال MCP می‌توان از ابزار `site_pairing_code` برای تولید همین کد استفاده کرد.

## نصب افزونه وردپرس

فایل اصلی افزونه در مسیر زیر است:

`plugins/developersia-ai/developersia-ai.php`

برای ساخت ZIP نصب وردپرس:

```bash
cd plugins
zip -r developersia-ai-connector-0.1.2.zip developersia-ai
```

در پیشخوان وردپرس به افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه بروید و فایل ZIP را نصب و فعال کنید. سپس از تنظیمات ← Developersia AI، آدرس API و کد اتصال را وارد کنید.

## دستورات بررسی

```bash
npm run typecheck
npm test

npx prisma validate
php -l plugins/developersia-ai/developersia-ai.php
```

## نکته مهم

برای محیط تولید از HTTPS، PostgreSQL مدیریت‌شده، پشتیبان‌گیری منظم، محدودسازی دسترسی شبکه و مدیریت امن secretها استفاده کنید. فایل `.env` نباید وارد Git شود.
