# اتصال Developersia AI به ChatGPT

سرور MCP در این پروژه از Streamable HTTP و OAuth 2.1 Authorization Code با PKCE (S256) استفاده می‌کند. این روش با اتصال سرورهای MCP راه دور در ChatGPT سازگار طراحی شده است.

## پیش‌نیازهای اتصال

- سرور روی دامنه عمومی با HTTPS معتبر منتشر شده باشد.
- مقدار `PUBLIC_BASE_URL` دقیقاً با دامنه عمومی سرور برابر باشد؛ برای نمونه `https://api.developersia.ir`.
- مسیر MCP در دسترس باشد: `https://api.developersia.ir/mcp`.
- مسیرهای OAuth discovery و authorization قابل دسترسی باشند:
  - `/.well-known/oauth-protected-resource/mcp`
  - `/.well-known/oauth-authorization-server`
  - `/oauth/register`
  - `/oauth/authorize`
  - `/oauth/token`
- یک حساب Developersia از طریق seed ایجاد شده باشد.

## اتصال از ChatGPT

1. در ChatGPT به بخش تنظیمات برنامه‌ها/اتصال‌ها بروید و گزینه افزودن اتصال یا MCP سفارشی را پیدا کنید. نام دقیق منو ممکن است با پلن و نسخه رابط کاربری متفاوت باشد.
2. آدرس MCP را وارد کنید: `https://api.developersia.ir/mcp`.
3. در صورت درخواست احراز هویت، OAuth را انتخاب کنید.
4. صفحه ورود Developersia باز می‌شود. با حساب خود وارد شوید.
5. دسترسی‌های درخواستی را بررسی و فقط در صورت رضایت تأیید کنید.
6. پس از اتصال، ابزارهای Developersia باید در فهرست ابزارهای قابل استفاده ظاهر شوند.

## ابزارهای نسخه اولیه

- `account_get`: اطلاعات حساب متصل.
- `sites_list`: فهرست سایت‌های متصل.
- `site_status`: وضعیت زنده WordPress.
- `posts_list`: فهرست یا جست‌وجوی مقاله‌ها و برگه‌ها.
- `post_read`: خواندن جزئیات یک محتوا.
- `post_create_draft`: ساخت پیش‌نویس جدید.
- `post_update_draft`: ویرایش محتوای پیش‌نویس یا در انتظار تأیید.

## نمونه درخواست برای آزمایش

«سایت‌های متصل من را نشان بده. سپس وضعیت سایت اول را بررسی کن و ۵ مقاله آخر را فهرست کن.»

برای آزمایش نوشتن:

«برای سایت اول یک پیش‌نویس مقاله با عنوان ... بساز. آن را منتشر نکن.»

## محدودیت‌ها

- این مخزن اپلیکیشن را به حساب ChatGPT شما نصب نمی‌کند؛ اتصال باید در تنظیمات ChatGPT انجام شود.
- دسترسی به MCP سفارشی ممکن است به نوع حساب، فضای کاری و سیاست‌های فعلی OpenAI وابسته باشد.
- در نسخه فعلی ایجاد محتوا فقط پیش‌نویس می‌سازد؛ انتشار مستقیم، حذف محتوا و تغییر تنظیمات حساس وردپرس ارائه نشده‌اند.
